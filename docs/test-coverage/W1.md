## 背景

`lib/utils/` は素材計算・検索・ブックマークのハッシュ生成といったアプリの中核ロジックが集まる層ですが、`material_calculator` / `resin_calculator` / `daily_material_weekday` / `text_style_parser` 以外はテストが 1 本もありません。特に `hash.dart` が生成する文字列は DB の主キーとして使われるため、無自覚な変更が既存ユーザーのブックマークを壊します。

この層は外部依存がほとんどない純粋関数なので、投入コストあたりのカバレッジ改善が最も大きくなります。
